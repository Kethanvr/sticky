# sticky

This repository is an Expo SDK 52 application scaffold using Expo Router. The current project structure provides the starting point for a cross-platform app; it does not yet document a product-specific feature set.

## Requirements

- Node.js and npm
- Expo Go, an Android emulator, or an iOS simulator for device testing

## Start the app

    npm install
    npx expo start

Use the Expo CLI options to open the app on a device, emulator, or web browser.

## Available scripts

- `npm run start` starts the Expo development server.
- `npm run android`, `npm run ios`, and `npm run web` start the corresponding target.
- `npm run lint` runs Expo's lint command.
- `npm test` starts Jest in watch mode.
